# Janus Blender Add-on Guide

This guide explains how to install the Janus Blender add-on, import it into Blender, and use the main UI panels for mesh setup, boundaries, visualization, and live simulation.

## Requirements

- Blender 4.0+ (the add-on is tagged for Blender 4.0+)
- A working Rust toolchain with `cargo`
- The Janus FFI library built from this repository

## 1. Build the Janus FFI library

From the repository root, run:

```bash
cargo build -p janus-ffi --release
```

This produces the shared library used by the add-on. The add-on can also build it from inside Blender via the UI button described below.

## 2. Install the add-on in Blender

### Option A: Install from a ZIP archive

1. From the repository root, create a ZIP archive containing the add-on folder:

```bash
cd /home/pana/dev2/janus
zip -r janus-cfd-blender.zip blender-addon
```

2. Open Blender.
3. Go to Edit > Preferences > Add-ons.
4. Click Install... and select the ZIP file you created.
5. Enable the add-on by checking the box next to "Janus CFD".

### Option B: Development workflow

If you are actively editing the add-on, you can also point Blender at the unpacked folder, but the ZIP install path is the most reliable for regular use.

## 3. Configure the shared library path

After enabling the add-on:

1. Open Edit > Preferences > Add-ons.
2. Find "Janus CFD".
3. Open its preferences.
4. Set the "Janus FFI Library" field to the built shared library, or use the built-in button in the panel to build it automatically.

The expected library names are:
- Linux: `libjanus_ffi.so`
- macOS: `libjanus_ffi.dylib`
- Windows: `janus_ffi.dll`

## 4. Use the add-on in Blender

Once the add-on is enabled, open the 3D Viewport sidebar (press `N` if needed) and find the Janus panel.

The add-on exposes three main panels:

### Simulation panel

Use this panel for setup and live runs.

- Build Janus FFI: builds the Rust library and copies it into the add-on bundle.
- Build Demo Grid: creates a simple demo mesh and writes a case file.
- Start Simulation / Stop Simulation: runs the live Janus solver and updates the viewport.
- Output Directory: where generated `.jvtk` frames and `manifest.json` are written.
- Steps / Tick and CFL: tuning values for the live solver loop.

### Boundaries panel

Use this panel to assign Blender objects to Janus boundary roles.

1. Select an object in the scene.
2. Choose a boundary role such as West, East, South, or North.
3. Click Assign Boundary.
4. The object is tagged for use by the case export workflow.

This is useful when you want the generated case to reflect the geometry of your Blender scene.

### Visualization panel

Use this panel to inspect fields and preview the mesh.

- Field: choose the field to display, such as density, temperature, or momentum.
- Thickness and Wireframe: change how the mesh is shown.
- Refresh Viewport: redraw the current visualization.

## 5. Import data into the add-on

The add-on supports importing Janus data generated by the solver or saved from previous runs.

### Import a manifest and frames

1. In the Janus panel, use the import operator to choose a `manifest.json` file.
2. The add-on will read the frame list and locate the matching `.jvtk` files.
3. The imported data is then available for visualization and timeline playback.

### Import a single `.jvtk` file

If you already have a single JVTK file, use the import JVTK action to load it into the scene.

## 6. Typical workflow

A simple workflow looks like this:

1. Enable the add-on and point it to the built shared library.
2. Create or select a mesh object in Blender.
3. Assign boundary objects in the Boundaries panel.
4. Use Build Demo Grid to create the base Janus domain mesh.
5. Import your manifest or JVTK data, or start a live simulation.
6. Use the Visualization panel to inspect the selected field.

## Troubleshooting

- If the add-on reports that the FFI library cannot be found, rebuild the library and confirm the path in the add-on preferences.
- If Blender cannot load the add-on, verify that the ZIP archive contains the `blender-addon` folder at its root.
- If the simulation panel buttons do not respond, check the Blender console for error messages and confirm that the shared library is compatible with the current build.
